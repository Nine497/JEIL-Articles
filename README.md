## Journal Reviewer Management System

**โครงงานปริญญาตรี ระบบจัดการผู้ตรวจทานบทความวิชาการ**

#### รายละเอียดโปรเจกต์

ระบบนี้พัฒนาขึ้นเพื่อช่วยในการจัดการและติดตามสถานะการประเมินบทความวิชาการ  
ผู้ใช้สามารถเพิ่ม แก้ไข ลบ และดูข้อมูลบทความ รวมถึงอัปเดตสถานะการประเมินบทความได้อย่างสะดวกและรวดเร็ว  
ระบบออกแบบให้ใช้งานง่ายบนทุกอุปกรณ์ พร้อมมีระบบยืนยันตัวตนเพื่อความปลอดภัย

#### ฟีเจอร์หลัก

- เพิ่ม แก้ไข ลบ และดูข้อมูลบทความวิชาการ  
- ติดตามสถานะการประเมินบทความแบบเรียลไทม์  
- ระบบยืนยันตัวตนผู้ใช้เพื่อความปลอดภัย  
- รองรับการใช้งานบนอุปกรณ์หลากหลายขนาด
